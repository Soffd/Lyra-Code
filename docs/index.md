## 关于本手册

本手册基于 Lyra Code 3.6.0 官方 README 与内置 Agent 工具契约编写，覆盖安装配置、Agent 工具体系、文件与代码编辑、命令执行、远程集成、微型服务器、Skills、记忆与子代理、定时任务、备份迁移、用量统计、安全实践与常见问题排查。

界面细节以实际版本为准，建议结合官方 [README_zh-CN.md](https://github.com/lyracode-app/Lyra-Code/blob/main/README_zh-CN.md) 阅读。
