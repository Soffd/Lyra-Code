## 1. Lyra Code 是什么


Lyra Code 是一个**面向 Android 的本地 AI Agent 应用**，把大模型对话、双栏文件管理器与代码编辑器、原生下载、命令执行、联网搜索、MCP 客户端/服务端、SSH、SMTP/IMAP 邮件、WebDAV、FTP/FTPS/SFTP、内置微型服务器、数据备份、Skills、设备诊断和用量统计整合到移动端。

与普通 AI 聊天应用的区别：

- **本地优先**：模型 Key、对话、文件、凭据都保存在本机，不经过第三方中转。
- **Agent 化**：AI 不只是回答，还能读文件、改代码、执行命令、操作远程服务器——每个动作都在你的审批控制之下。
- **端侧工程能力**：以 Android 系统为中心，同时通过 Termux 提供真实 Shell 能力。
- **可扩展**：通过 Skills、MCP、定时任务和可配置的 Agent 工具，几乎可以覆盖个人自动化与轻量工程工作流。

### 1.1 适合谁用

- 想在手机上做代码编辑、脚本执行、文件管理的开发者；
- 需要让 AI 处理邮件、云盘、FTP 服务器、远程主机等日常事务的效率用户；
- 想搭建本地知识库、自动化写作/学习流水线的内容创作者；
- 希望在可控权限下体验 Agent 自主工作的进阶用户。

### 1.2 核心能力速览

| 能力域 | 具体内容 |
| --- | --- |
| 模型接入 | OpenAI 兼容接口、Anthropic Messages、Gemini GenerateContent，多服务商并存 |
| Agent 工具 | 工作区/全局文件操作、原生下载、Termux 命令、TODO 规划、联网搜索、定时任务 |
| 文件与代码 | 双栏文件管理器、Sora Editor（TextMate 语法高亮）、编辑器内 AI 侧栏 |
| 远程集成 | MCP 客户端/服务端、SSH、IMAP/SMTP、WebDAV、FTP/FTPS/SFTP |
| 服务器 | 内置 HTTP/HTTPS 静态服务器 + 实时日志 |
| 扩展 | Skills 能力包（zip / SKILL.md / Git 仓库导入） |
| 数据 | 本地 zip 备份、WebDAV 云备份、补充导入去重 |
| 系统 | 设备信息、硬件检查 Agent、应用列表、可选 Shizuku/Root |
| 统计 | 离线 Token 估算、日/周/月/年/区间用量统计 |

## 2. 安装与初始配置


### 2.1 安装

1. 从 GitHub Releases / Gitee 下载最新 APK 安装；
2. Android 8.0（API 26）及以上均可运行；
3. 首次启动会请求必要权限（存储、通知等），按引导授予。

### 2.2 授予文件管理器「管理所有文件」权限

双栏文件管理器默认根目录为 `/storage/emulated/0`，需要「管理所有文件」权限（Android 11+ 的 `MANAGE_EXTERNAL_STORAGE`）：

```text
设置 → 应用 → Lyra Code → 权限 → 所有文件访问权限 → 允许
```

未授权时，文件浏览与批量操作会受限。

### 2.3 配置 Termux（命令执行的前置条件）

`run_command` 依赖 Termux 的 RunCommandService。首次使用前需在 Termux 内开启外部应用调用：

```bash
mkdir -p ~/.termux && (grep -qxF 'allow-external-apps=true' ~/.termux/termux.properties || echo 'allow-external-apps=true' >> ~/.termux/termux.properties) && termux-reload-settings
```

然后在 Lyra Code 的 **设置页** 中授予 Termux 通信权限。**未授权时 `run_command` 会自动禁用。**

建议同时安装 Termux 基础包：

```bash
pkg update && pkg install git openssh python nodejs-lts ripgrep file
```

::: tip 说明
`run_command` 以 Termux 应用用户身份运行，**不是 root**，也不是 Shizuku Shell。需要系统级操作时，另行配置 Shizuku 或 Root 工具（见第 7 章）。
:::

### 2.4 设置页要点

| 配置项 | 说明 |
| --- | --- |
| 模型服务商 | 管理多个 API 服务商、Key、Base URL、默认模型 |
| 系统提示词 | 自定义全局 System Prompt，可多套保存、快速切换 |
| Termux 权限 | 开启/关闭命令执行通道 |
| 联网搜索黑名单 | 屏蔽不想让 AI 打开的域名 |
| Agent 工具开关 | 逐个启用/禁用系统级工具 |
| 主题/字体/刷新率 | 显示相关偏好 |
| 备份 | 导出/导入本地或 WebDAV 备份 |
