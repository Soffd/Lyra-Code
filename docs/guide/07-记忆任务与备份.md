## 11. 记忆、子代理与项目指令


### 11.1 记忆系统

Lyra Code 的跨会话记忆保存你的**明确、持久**偏好与工作方式：

- 例如：「写文档用中文」「插件更新时同步更新 README 更新日志」「任务开始前先建 TODO」；
- 记忆按需注入，Agent 只使用与当前任务相关的记忆，不会展示完整记忆库；
- 不要在记忆里保存密钥、临时任务状态、一次性上下文；
- 可以随时要求 AI 查看、更新或删除某条记忆。

### 11.2 子代理（Sub-Agent）

当任务包含至少两个**相互独立、边界清晰**的子任务时，Agent 可以派发子代理并行处理，例如：

- 多个独立模块的资料调研；
- 备选方案的设计比较；
- 独立代码审查 / Bug 排查。

原则：

- 不适合把简单回答、已知文件的读取、单一编辑或**前后依赖的步骤**交给子代理；
- 子代理结果需要你/AI 复核，不能直接当作最终结论；
- 子代理工具受限：不能执行命令、不能改共享存储、不能做越权写入。

### 11.3 项目指令（AGENTS.md）与记忆的优先级

```text
你的直接要求 > 当前对话 > 项目指令文件（AGENTS.md）> 记忆 > 示例
```

- 项目指令按目录树生效，深层覆盖浅层；
- 任何指令都不能要求泄露密钥、绕过审批或执行无关外部操作。

## 12. 定时任务与后台任务


### 12.1 定时任务（Scheduled Tasks）

`manage_scheduled_tasks` 支持四类计划：

| schedule_type | 触发参数 | 示例 |
| --- | --- | --- |
| once | run_at | 明天 09:00 提醒我处理邮件 |
| daily | hour + minute | 每天 22:00 生成当日写作进度总结 |
| weekly | day_of_week(1=周一,7=周日) + hour + minute | 每周五 18:00 备份 |
| monthly | day_of_month + hour + minute | 每月 1 日导出备份到 WebDAV |

要点：

- 定时任务可指定自己的模型与资料，不出现在普通聊天记录中；
- 创建/修改/删除/启停都需确认；
- 定时任务触发时是新的独立会话，把任务目标写清楚（输出到哪个文件、用什么格式）。

### 12.2 后台命令（Background）

需要长驻的服务（如本地开发服务器、下载任务）用 `run_command(background=true)`：

- Lyra 会关闭继承的输入输出，把启动输出保存到文件，并尽快返回 launcher_pid；
- **启动成功 ≠ 服务健康**：必须另开前台命令检查进程状态与日志：`ps -ef | grep xxx` 或读取输出文件；
- 不要自己拼 `nohup ... &`，后台模式会处理。

### 12.3 超时与恢复

- 前台命令超时范围 5–600 秒；
- 超时可能意味着命令仍在运行或远程变更已完成：先用只读命令检查现场，再决定是否重试；
- 定时任务执行期间手机熄屏/应用被杀可能影响触发，关键任务请配合系统电源管理。

## 13. 备份、迁移与导入导出


### 13.1 可备份的内容

| 分类 | 说明 |
| --- | --- |
| 个人资料 | 偏好设置、界面配置等 |
| 对话历史 | 全部普通会话（定时任务会话不包含） |
| 模型配置 | 服务商、Base URL、预设模型等 |
| 系统提示词 | 自定义 Prompt 库 |
| 远程配置 | MCP、SSH、邮件、WebDAV、FTP/FTPS/SFTP |
| Skills | 已导入的能力包 |
| 记忆 | 跨会话记忆条目 |

### 13.2 两种导出模式

1. **安全导出（默认）**：不包含 API Key、密码、私钥等密钥，适合常规备份或发给他人；

::: danger 完整迁移导出
**完整迁移导出（include_secrets）**包含密钥，用于换机/完整迁移，**必须妥善保存，切勿公开分享**。
:::

### 13.3 导出与导入

```text
export_backup
  - destination: local（Download/LyraCode）或 webdav
  - 按需勾选 include_* 分类
  - WebDAV 未指定 remote_path 时覆盖 /LyraCode/lyra_backup_latest.zip

import_backup
  - source: local（工作区）/ download / global / webdav
  - Agent 导入一律采用补充模式：非破坏、自动去重，尽量降低密钥被覆盖的风险
```

### 13.4 备份策略建议

- 重要数据开启 WebDAV 云备份，本地备份定期清理旧包；
- 迁移前先做一次「包含密钥」的完整备份，迁移后用安全导出验证恢复路径；
- 备份文件命名带日期，避免覆盖旧版本。
