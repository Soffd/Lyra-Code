## 3. 界面总览


### 3.1 四大区域

1. **AI 对话页**：与 Agent 交互的主战场；底部动作面板可快速切换服务商、模型、系统提示词。
2. **双栏文件管理器**：默认进入 `/storage/emulated/0`，两栏独立导航，用于跨目录复制、移动、重命名、删除、解压；长按 `.html`/`.htm` 可调用浏览器预览。
3. **代码编辑器（Sora Editor）**：行号、TextMate 语法高亮、文件内搜索、跳转行、自动换行；UTF-8 解码异常会警告；覆盖修改前自动在同目录生成 `.bak` 备份。
4. **Agent 工具页**：展示并管理当前可用的工具集合与配置。

### 3.2 编辑器内的 AI 侧栏

在编辑器中**向右滑动**可打开专用 AI 对话侧栏：

- 静默传入当前文件路径，AI 直接针对该文件回答或修改；
- 可添加项目工作目录，让 AI 了解项目上下文；
- 审批与工具输出保留在编辑页内可见；
- AI 的修改会以可视化方式**重放**到当前打开的文档，便于审查差异。

这是「边看代码边让 AI 改」的核心工作流入口，比在全局对话中描述路径更精确。

### 3.3 快速上手三步

1. 在设置中添加你的模型服务商（支持 OpenAI 兼容 / Anthropic / Gemini）；
2. 通过文件管理器或 AI 在 `/storage/emulated/0/Lyra` 建立工作区（Workspace）；
3. 在对话中让 AI「列出工作区内容 / 创建一个 TODO / 修改某个文件」，观察审批流。

## 4. 模型与多服务商配置


### 4.1 支持的协议

| 协议 | 说明 |
| --- | --- |
| OpenAI Chat Completions 兼容 | 大多数兼容网关（OpenAI、DeepSeek、Moonshot、本地 Ollama/vLLM 等） |
| Anthropic Messages API | Claude 系列 |
| Gemini GenerateContent API | Google Gemini 系列 |

### 4.2 配置项

- **服务商名称**：自定义，便于识别；
- **API Key**：保存在本机，备份时默认不导出密钥（除非选择包含密钥的完整迁移备份）；
- **Base URL**：自建网关或代理地址；支持 HTTP，但会提示明文风险；
- **预设模型**：常用模型名；
- **自定义系统提示词**：可多套保存；
- **推理深度**：推理类模型（如 o 系列 / R 系列）的 reasoning effort 预设。

### 4.3 切换技巧

对话底部的动作面板支持**一键切换服务商 / 模型 / 提示词**：

- 同一任务中比较多个模型输出时，先切换模型再继续对话；
- 为不同场景（编码 / 写作 / 翻译 / 诊断）保存独立系统提示词，切换提示词即可改变 Agent 的行为基线；
- 私有化部署（Ollama / vLLM / LM Studio）走 OpenAI 兼容协议，Base URL 填局域网或本机地址。
