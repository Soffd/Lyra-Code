## 14. 用量统计与设备诊断


### 14.1 用量统计

- 统计维度：对话数、消息数、用户输入 Token、AI 输出 Token；
- 思维链、工具上下文、文件读取、命令输出、重复上下文都会计入；
- **离线 Token 估算**，不依赖网络，不把数据发给第三方；
- 支持日 / 周 / 月 / 年 / 总计与历史区间查询。

用途：

- 评估不同模型/提示词的 token 消耗，优化成本；
- 观察 Agent 任务中工具调用与文件读取的占比，定位「上下文膨胀」来源。

### 14.2 设备诊断

- **手机信息页**：厂商、型号、Android 版本、CPU/硬件、ABI、内存、存储、屏幕、网络、蓝牙、电池；
- **硬件检查 Agent**：机型诊断、问题排查、硬件对比（用 `get_device_hardware_info`）；
- **应用列表**：识别已安装应用（`list_installed_apps`，可查询包名/版本/签名）。

提示：

- 这些信息用于排查与合理推测，不能当作设备真伪的绝对证明；
- 结合 Shizuku 的 `dumpsys` / `pm` 命令可进一步定位系统级问题。

## 15. 多模态、主题与内容渲染


### 15.1 图片与媒体

- 上传图片、拍照上传，支持裁剪、旋转、画笔标注、马赛克标注；
- 用户与 AI 的图片/视频支持缩略图、预览、保存；
- AI 返回的 base64、URL、本地媒体文件可预览与另存；
- 附件为多模态内容或提取文本，取决于当前模型能力。

### 15.2 渲染能力

- Markdown、表格、语法高亮代码块；
- LaTeX 数学公式（JLaTeXMath 本地渲染）；
- 媒体 Data URL 渲染。

### 15.3 主题与显示

| 设置 | 说明 |
| --- | --- |
| 主题模式 | 浅色 / 深色 / 跟随系统 |
| Material You | 动态配色，只调颜色不动布局 |
| 字体大小 | 实时预览，可跟随系统或自定义更宽范围 |
| 刷新率 | 系统智能 / 30 / 60 / 90 / 120 Hz，最终取决于屏幕与系统策略 |
